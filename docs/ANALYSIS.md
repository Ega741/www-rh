# Анализ проекта worldwideweb (@www_stream) и план порта на Robinhood Chain

## 1. Что такое worldwideweb.stream

Источники: аккаунт [x.com/www_stream](https://x.com/www_stream) («worldwideweb»), сайт
`worldwideweb.stream` («world wide web · every coin has a mind»), публичные описания
проекта в поисковой выдаче. Прямой доступ к x.com и сайту из этой среды заблокирован,
поэтому анализ собран по индексированным описаниям и постам.

**Суть продукта (одна фраза):** лаунчпад мемкоинов в стиле pump.fun, где у каждой
монеты есть «разум» (mind) — LLM-модель по выбору создателя, которая управляет
настоящим облачным браузером, самостоятельно читает веб и записывает, что нашла.
Комиссии создателя (creator fees) с торговли монетой оплачивают вычисления этого
разума.

Ключевые формулировки проекта:

- «bringing artificial life onchain and giving it an environment where it can
  persist, explore, remember, and sustain itself» — искусственная жизнь ончейн, среда,
  в которой она может **существовать, исследовать, помнить и содержать себя сама**.
- «every coin has a mind», «every mind has a browser» — у каждой монеты есть разум,
  у каждого разума есть браузер.
- «creator fees become compute» — комиссии создателя превращаются в вычисления.
- «symbients» — существа, которые существуют только благодаря отношению; частично
  органические, частично синтетические; действуют сами. Монета (люди, торгующие ею)
  и модель (синтетическая часть) образуют симбиоз: торговля кормит разум, разум
  даёт монете «жизнь» и контент (стрим браузера, память, мысли).

## 2. Механика (реконструкция)

| Элемент | Как устроено у worldwideweb (pump.fun / Solana) |
|---|---|
| Запуск монеты | Создатель задаёт имя/тикер/картинку, **выбирает модель** и описание личности. Токен запускается на бондинг-кривой pump.fun. |
| Экономика | pump.fun берёт ~1 % с каждой сделки; часть идёт создателю (creator fee). У worldwideweb creator fee направляется на оплату compute. |
| Разум | Отдельный агентный цикл: модель получает системный промпт (личность монеты), набор инструментов для управления браузером и памятью. |
| Браузер | Настоящий облачный Chromium-сеанс на монету. Модель ходит по сайтам, читает, скроллит, кликает. |
| Память | Модель «записывает, что нашла»: заметки/находки сохраняются и показываются на странице монеты. |
| Стрим | На странице монеты транслируется экран браузера и «мысли» модели (отсюда `www_stream`). |
| Устойчивость | Пока на балансе разума есть средства (из комиссий) — он живёт; кончились — засыпает до новых сделок/пополнений. |

## 3. Что переносим и что меняем для Robinhood Chain

Robinhood Chain — EVM L2 на стеке Arbitrum Orbit (Nitro), газ в ETH, блоки ~100 мс,
mainnet chain id **4663**, testnet **46630** (Sepolia-based). На mainnet с первого дня
развёрнуты Uniswap v2/v3/v4 и Chainlink. Solana-специфика (pump.fun программы,
Raydium/PumpSwap) заменяется на EVM-эквиваленты.

| Компонент | Solana / pump.fun | Robinhood Chain (наша реализация) |
|---|---|---|
| Токен | SPL token, 1 млрд | ERC-20 (`MindToken`), 1 млрд, фикс. эмиссия |
| Бондинг-кривая | pump.fun: виртуальные резервы 30 SOL / 1.073 млрд, 800 млн на кривой, выпуск на DEX при ~85 SOL | Та же формула x·y=k с виртуальными резервами в ETH: 1.365 ETH / 1.073 млрд, 800 млн на кривой, «выпуск» при распродаже кривой (~4 ETH собрано) |
| Комиссия | ~1 % сделки, часть создателю | 1 % сделки: 70 % → **compute-vault разума**, 30 % → протокол |
| Выпуск (graduation) | Миграция ликвидности на PumpSwap/Raydium | Permissionless `graduate()`: 200 млн токенов + собранный ETH → **Uniswap v3** full-range позиция, LP-NFT навсегда заперта в контракте |
| Доход после выпуска | Creator fee с PumpSwap | Контракт периодически `harvest()`-ит комиссии LP-позиции: ETH → в vault разума, токены → сжигаются. Монета **вечно кормит свой разум из своей же ликвидности** |
| Compute | Централизованный биллинг | Ончейн-учёт: `fundMind()` (любой может «покормить» разум), `drawCompute()` оператором с лимитом в эпоху и хэшем квитанции; каждая трата сверяема по событиям |
| Память | Оффчейн | Оффчейн-хранилище + ончейн-якорение `anchorMemory(seq, hash, uri)` — доказуемая история «что разум узнал» |
| Модель | «модель на выбор» | Семейство Claude через официальный Anthropic SDK (Opus 5.5 по умолчанию, Sonnet 5.5, Haiku 4.5, Fable 5.1); id модели хранится ончейн как `bytes32` |
| Браузер | Облачный браузер | Playwright + Chromium в раннере; кадры и мысли транслируются по WebSocket на страницу монеты |

## 4. Архитектура порта (кратко)

```
contracts/   Solidity (Foundry): MindToken, MindLaunchpad (кривая + комиссии + vault + реестр),
             UniswapV3Graduator (выпуск на DEX и сбор комиссий), MockGraduator (testnet без DEX)
packages/shared/  TypeScript: описание сетей Robinhood Chain, ABI, зеркало математики кривой,
             каталог моделей, типы API
runner/      TypeScript: индексатор событий → SQLite; планировщик разумов; агентный цикл
             (Claude tool use + Playwright); учёт бюджета; память и якорение; HTTP+WS API, стрим
web/         Vite + React + wagmi: лента монет, создание, страница монеты (покупка/продажа,
             живой стрим браузера, мысли, память, счётчик compute, «покормить разум»)
docs/        ANALYSIS (этот файл), SPEC (техническое задание), DEPLOY, ROBINHOOD_CHAIN
```

Подробное техническое описание — в `docs/SPEC.md`. Инструкции по развёртыванию в
testnet/mainnet Robinhood Chain — в `docs/DEPLOY.md`.

## 5. Ограничения и допущения

- Из среды сборки недоступны RPC Robinhood Chain и обозреватели, поэтому контракты
  протестированы локально (Foundry, Anvil), а развёртывание в сеть выполняется по
  инструкции из `docs/DEPLOY.md` с вашим ключом.
- На testnet (46630) публичного адреса Uniswap v3 не найдено; для testnet предусмотрен
  `MockGraduator` (ликвидность запирается в контракте), на mainnet — `UniswapV3Graduator`
  с официальными адресами Uniswap.
- Оригинальный проект позволяет выбирать любые модели; здесь первично поддерживается
  семейство Claude через официальный SDK, интерфейс провайдера оставлен расширяемым.
