# www-rh — technical specification

**Product:** "worldwideweb on Robinhood Chain" — a pump.fun-style launchpad where every coin has a
*mind*: an LLM (Claude) driving a real headless browser, reading the web on its own, remembering what
it finds, and sustaining itself from the coin's trading fees. Port of worldwideweb.stream
(`@www_stream`, Solana/pump.fun) to **Robinhood Chain** (Arbitrum Orbit L2, chain id 4663 mainnet /
46630 testnet, gas in ETH). See `docs/ANALYSIS.md` (RU) for the product analysis and
`docs/ROBINHOOD_CHAIN.md` for chain details and addresses.

This document is the contract between packages. Names, signatures, events, errors, JSON shapes,
env vars and formulas here are normative; implementers must not rename, add or drop them without
updating this file. "MUST"/"MUST NOT" are requirements, "SHOULD" are strong defaults.

### 0.1 Global conventions

- Token amounts have 18 decimals; ETH amounts are wei. In TypeScript both are `bigint`; on the
  wire (API, WS, canonical JSON) both are **decimal strings** (no leading zeros, no sign, `"0"` for zero).
- Every API/WS field holding wei is named with a `Wei` suffix. Token amounts keep plain names
  (`tokensSold`, `tokenAmount`) and are decimal strings too.
- USD inside the runner is integer **micro-dollars** (`1 USD = 1_000_000`), named `…UsdMicro`.
  On the API/WS, USD is a JS `number` in dollars rounded to 6 decimals, named `…Usd`.
- Addresses: lowercase `0x` hex in API/WS payloads and in hashed objects; EIP-55 checksummed in TS
  constants. bytes32 values: lowercase `0x` + 64 hex.
- Timestamps on the wire: ISO-8601 UTC with milliseconds (`Date.prototype.toISOString()`, e.g.
  `2026-10-02T10:00:00.000Z`). On-chain timestamps are unix seconds.
- Nullability: every field of an API/WS DTO is always present; unknown values are `null`
  (zod `.nullable()`, never `.optional()`). The only exception is the `MindMetadata` document
  (`POST /api/metadata` body and `GET /api/metadata/:hash` response), whose optional keys are absent
  when unset.
- Hashes over JSON use the canonical JSON encoding of §3.2.

## 1. Economics (normative constants)

| Name | Value | Meaning |
|---|---|---|
| `TOTAL_SUPPLY` | `1_000_000_000e18` | minted once to the launchpad at creation |
| `CURVE_SUPPLY` | `800_000_000e18` | sold on the bonding curve |
| `LP_SUPPLY` | `200_000_000e18` | reserved; goes to the DEX at graduation |
| `VIRTUAL_ETH` | `1.365 ether` | virtual ETH reserve (x₀) |
| `VIRTUAL_TOKENS` | `1_073_000_000e18` | virtual token reserve (y₀) |
| `tradeFeeBps` | `100` (1 %) | fee on every curve buy/sell; owner-settable, max 500 |
| `mindShareBps` | `7000` (70 %) | share of every trade and graduation fee credited to the coin's **mind vault**; the rest → protocol; max 10000 |
| `graduationFeeBps` | `250` (2.5 %) | taken from the real ETH reserve at graduation, split by `mindShareBps`; max 1000 |
| `creationFee` | `0` | flat fee to create a mind; owner-settable; credited 100 % to `protocolBalance` |
| `maxDrawPerEpoch` / `drawEpoch` | `0.25 ether` / `1 day` (86400 s) | absolute per-mind cap on operator compute draws per epoch; owner-settable, `drawEpoch >= 1 hour`, `maxDrawPerEpoch <= MAX_DRAW_PER_EPOCH = 2 ether` (fixed epochs allow a 2× burst at an epoch boundary) |
| `graduationGrace` | `1 day` | after `completedAt + graduationGrace` a curve stuck in `Complete` accepts sells again (first sell reopens it to `Bonding`, `CurveReopened`); owner-settable within [1 hour, 30 days] |

Fee parameters are global: `setFeeParams` applies immediately to every mind, including curves in
progress (there is no per-mind snapshot). Constants other than the fee parameters, `creationFee` and
the draw limit are immutable.

**Curve.** Constant product with virtual reserves. For every quote and trade, recompute from the
current state (never store `k`):
`x = VIRTUAL_ETH + realEthReserve`, `y = VIRTUAL_TOKENS - tokensSold`, `k = x·y`, `f = tradeFeeBps`.
All divisions floor unless written `ceilDiv`; rounding always favours the contract, so `x·y` never
decreases across trades and a sell can never take out more than `realEthReserve`.

- **quoteBuy(ethIn)** → `(tokensOut, ethUsed, fee)`; requires `ethIn > 0`, phase `Bonding`:
  1. `fee = ethIn·f / 10000`, `net = ethIn - fee`, `tokensOut = y - ceilDiv(k, x + net)`.
  2. `remaining = CURVE_SUPPLY - tokensSold`. If `tokensOut > remaining` (the completing buy):
     `tokensOut = remaining`, `net' = ceilDiv(k, y - remaining) - x`,
     `fee' = ceilDiv(net'·f, 10000 - f)`, `ethUsed = net' + fee'`; guard: if `ethUsed > ethIn`
     (rounding at the threshold) then `ethUsed = ethIn` and `fee' = ethIn - net'`. Return
     `(tokensOut, ethUsed, fee')`. (`net' <= net` always holds.)
  3. Otherwise return `(tokensOut, ethIn, fee)` (`ethUsed = ethIn`).
  State after a buy: `realEthReserve += ethUsed - fee` (i.e. `net` or `net'`),
  `tokensSold += tokensOut`; the returned `fee` is split by `mindShareBps`; `ethIn - ethUsed` is
  refunded to the buyer. If `tokensSold == CURVE_SUPPLY` the phase becomes `Complete`.
- **quoteSell(tokensIn)** → `(ethOut, fee)`; requires `0 < tokensIn <= tokensSold`, phase `Bonding`:
  `ethGross = x - ceilDiv(k, y + tokensIn)`, `fee = ethGross·f / 10000`, `ethOut = ethGross - fee`.
  State after: `realEthReserve -= ethGross`, `tokensSold -= tokensIn`.
- **Fee split** (every trade fee and the graduation fee): `mindAmount = fee·mindShareBps / 10000`,
  `protocolAmount = fee - mindAmount`.
- **currentPrice** (wei per 1e18 tokens) `= x·1e18 / y`. Market cap (display, wei) `= price·TOTAL_SUPPLY / 1e18`.
  Progress (bps) `= tokensSold·10000 / CURVE_SUPPLY`.
- Buys are allowed only while phase == `Bonding`; sells while `Bonding`, or while `Complete` once
  `block.timestamp >= completedAt + graduationGrace` (the sell flips the phase back to `Bonding`, see §2.3).
  Completion needs exactly `4.0 ETH` of net reserve (`1.365·800/273`), ≈ 4.04 ETH gross including fees.
- **Graduation** (phase `Complete` → `Graduated`): `gradFee = realEthReserve·graduationFeeBps / 10000`
  (split mind/protocol), `ethLiquidity = realEthReserve - gradFee`, `tokenLiquidity = LP_SUPPLY`.
  Final curve price `≈ 1.965e-8 ETH` (mcap ≈ 19.65 ETH), LP opening price `≈ 1.95e-8 ETH`
  (slightly below, as on pump.fun). After graduation `realEthReserve = 0`, `tokensSold` stays
  `CURVE_SUPPLY`.

The Solidity library `CurveMath` (§2.3) and the TypeScript mirror (`@www-rh/shared` `curve.ts`)
MUST reproduce these bigint formulas exactly. `packages/shared/fixtures/curve.json` (generated by
Foundry, §2.6) is checked in and used by both `forge test` and `vitest` to prove equivalence.

### 2.2 `IGraduator` — `src/interfaces/IGraduator.sol`

```solidity
interface IGraduator {
    /// @notice The launchpad allowed to call graduate/harvest.
    function launchpad() external view returns (address);

    /// @notice Deploys liquidity for `token`. The launchpad has already transferred `tokenAmount`
    ///         of `token` to this contract and sends the ETH liquidity as msg.value.
    ///         Before returning, the graduator MUST send exactly `ethReturned` wei back to the
    ///         launchpad (unused ETH) with one or more full-gas plain calls (`call{value: …}("")`,
    ///         never `transfer`/`send`: the launchpad's receive() writes storage), and burn unused
    ///         tokens to 0x…dEaD.
    /// @return pool        DEX pool that received the liquidity (address(this) for the mock)
    /// @return positionId  LP position id (0 when not applicable)
    /// @return ethReturned wei sent back to the launchpad during this call
    function graduate(address token, uint256 tokenAmount)
        external payable returns (address pool, uint256 positionId, uint256 ethReturned);

    /// @notice Collects DEX fees for `token`. Before returning, sends exactly `ethOut` wei to the
    ///         launchpad with full-gas plain calls (as above) and burns collected tokens
    ///         (`tokensBurned`) to 0x…dEaD.
    function harvest(address token) external returns (uint256 ethOut, uint256 tokensBurned);
}
```

Both functions are callable only by `launchpad()` (implementations revert `NotLaunchpad()`). During
each call the launchpad's `receive()` accepts ETH only from that graduator and counts it; the
launchpad then requires the count to equal `ethReturned` / `ethOut` (§2.3 rules 4–6). ETH that
reaches the launchpad any other way (e.g. through `fundMind`, which is `nonReentrant`, a forced
transfer, or from another address) is not counted.

### 2.3 `MindLaunchpad` — `src/MindLaunchpad.sol`

Single core contract: factory + bonding curve + fee router + mind vault + mind registry.
`contract MindLaunchpad is IMindLaunchpad, Ownable2Step, Pausable, ReentrancyGuard`.

**`src/libraries/CurveMath.sol`** — `library CurveMath` with the §1 constants (`TOTAL_SUPPLY`,
`CURVE_SUPPLY`, `LP_SUPPLY`, `VIRTUAL_ETH`, `VIRTUAL_TOKENS`, `BPS = 10_000`) and internal pure
functions, used by the launchpad and by the fixture generator:
`quoteBuy(uint256 realEthReserve, uint256 tokensSold, uint256 ethIn, uint256 tradeFeeBps) returns (uint256 tokensOut, uint256 ethUsed, uint256 fee)`,
`quoteSell(uint256 realEthReserve, uint256 tokensSold, uint256 tokensIn, uint256 tradeFeeBps) returns (uint256 ethOut, uint256 fee)`,
`price(uint256 realEthReserve, uint256 tokensSold) returns (uint256)`,
`marketCap(uint256 realEthReserve, uint256 tokensSold) returns (uint256)`,
`progressBps(uint256 tokensSold) returns (uint256)`,
`splitFee(uint256 fee, uint256 mindShareBps) returns (uint256 mindAmount, uint256 protocolAmount)`.
`quoteSell` assumes `tokensIn <= tokensSold` (the launchpad checks it).

**Rules** (checks are listed in evaluation order; `onlyMind` = revert `NotAMind()` unless `isMind(token)`):

1. `createMind` — `whenNotPaused`, `nonReentrant`. Checks: `bytes(name).length` in 1..64 else
   `InvalidName()`; `bytes(symbol).length` in 1..16 else `InvalidSymbol()`;
   `bytes(metadataURI).length <= 2048` else `MetadataTooLong()` (empty is allowed);
   `modelId != 0` else `InvalidModel()`; `msg.value >= creationFee` else `InsufficientCreationFee()`.
   Effects: `token = address(new MindToken(name, symbol, address(this), msg.sender))`; store
   `MindInfo{creator: msg.sender, …, createdAt: block.timestamp, status: Alive}`, zeroed
   `CurveState` (phase `Bonding`), push to `_minds`; emit `MindCreated`. If `creationFee > 0`:
   `protocolBalance += creationFee`, emit `FeeAccrued(token, 0, creationFee)`. If
   `ethIn = msg.value - creationFee > 0`, execute a buy for `msg.sender` with `ethIn` and
   `minTokensOut` (rule 2, no deadline); otherwise `minTokensOut` is ignored.
2. `buy` — `whenNotPaused`, `nonReentrant`, `onlyMind`. `block.timestamp > deadline` → `Expired()`;
   `msg.value == 0` → `ZeroAmount()`; phase != `Bonding` → `WrongPhase()`. Quote with `ethIn = msg.value`
   (§1); `tokensOut == 0` → `ZeroAmount()`; `tokensOut < minTokensOut` → `Slippage()`. Effects:
   update reserves (`realEthReserve += ethUsed - fee`, `tokensSold += tokensOut`), split `fee`
   (`mindBalance += mindAmount`, `protocolBalance += protocolAmount`), emit
   `FeeAccrued(token, mindAmount, protocolAmount)`, emit `Trade(token, buyer, true, ethUsed,
   tokensOut, fee, realEthReserve, tokensSold)` (post-trade reserves); if `tokensSold == CURVE_SUPPLY`:
   phase = `Complete`, `completedAt[token] = block.timestamp`, emit `CurveCompleted(token, realEthReserve)`.
   Buys require `Bonding` (a `Complete` curve is never reopened by a buy). Interactions: transfer
   `tokensOut` to the buyer, then refund `ethIn - ethUsed` (non-zero only on the completing buy).
3. `sell` — `nonReentrant`, `onlyMind` (not pausable). `Expired()`; `tokensIn == 0` → `ZeroAmount()`;
   `WrongPhase()` unless phase == `Bonding`, or phase == `Complete` and
   `block.timestamp >= completedAt[token] + graduationGrace` (escape hatch for a coin that could not be
   graduated; the grace is read at sell time, so `setGraduationGrace` applies to curves already waiting).
   In the latter case the sell first reopens the curve: phase = `Bonding`, `completedAt[token] = 0`, emit
   `CurveReopened(token)` (before the sell's `FeeAccrued`/`Trade`; reverted with the sell if any later check
   fails); the curve can then be bought out again, which records a new `completedAt` and starts a new grace.
   `tokensIn > tokensSold` → `ExceedsTokensSold()`. Quote (§1); `ethOut == 0` →
   `ZeroAmount()`; `ethOut < minEthOut` → `Slippage()`. Pull `tokensIn` with `safeTransferFrom`
   (seller approves the launchpad, or uses `permit` on the token beforehand); update reserves
   (`realEthReserve -= ethOut + fee`, `tokensSold -= tokensIn`); split fee + `FeeAccrued`;
   `Trade(token, seller, false, ethOut, tokensIn, fee, realEthReserve, tokensSold)`; send `ethOut`.
   **`Trade.ethAmount` is `ethUsed` (fee included, refund excluded) for buys and `ethOut` (fee
   excluded) for sells; `Trade.fee` is the total fee.** Gross ETH of a sell = `ethAmount + fee`.
4. `graduate(token)` — permissionless, `nonReentrant`, `onlyMind`, not pausable. Phase != `Complete`
   → `WrongPhase()`; `grad = graduator`, `grad == address(0)` → `GraduatorNotSet()`.
   Graduation stays possible for as long as the phase is `Complete` (also after the grace period).
   Effects: `gradFee`, split + `FeeAccrued(token, mindFee, protocolFee)`; `ethLiquidity =
   realEthReserve - gradFee`; `realEthReserve = 0`; phase = `Graduated`; `graduatorOf[token] = grad`.
   Interactions: `safeTransfer(grad, LP_SUPPLY)`; open the return window (`_returnFrom = grad`,
   `_returned = 0`); `(pool, positionId, ethReturned) = IGraduator(grad).graduate{value: ethLiquidity}(token, LP_SUPPLY)`;
   read the count, close the window (`_returnFrom = address(0)`, `_returned = 0`) and require
   `count == ethReturned` else `EthReturnMismatch()` (no balance-delta check). Then store `pool`/`positionId`; if `ethReturned > 0`:
   `mindBalance[token] += ethReturned`, emit `MindFunded(token, grad, ethReturned)`; finally emit
   `Graduated(token, pool, positionId, ethLiquidity, LP_SUPPLY, gradFee)` (`ethLiquidity` = ETH
   sent to the graduator, before the return). If the graduator call reverts (e.g. `PoolPriceSkewed`,
   §2.4), the whole tx reverts, the coin stays `Complete` and anyone may retry; recovery is the pool
   being arbitraged, the owner wiring a corrected graduator with `setGraduator`, or holders selling
   after the grace period (rule 3).
5. `harvest(token)` — permissionless, `nonReentrant`, `onlyMind`. Phase != `Graduated` →
   `WrongPhase()`. `grad = graduatorOf[token]` (the graduator that performed the graduation, never
   the current one); open the return window for `grad`; `(ethOut, tokensBurned) =
   IGraduator(grad).harvest(token)`; read the count, close the window and require `count == ethOut`
   else `EthReturnMismatch()`; if `ethOut > 0`: `mindBalance[token] += ethOut`, emit
   `MindFunded(token, grad, ethOut)`; emit `Harvested(token, ethOut, tokensBurned)`.
6. `receive()` — reverts `DirectEthNotAccepted()` unless `msg.sender == _returnFrom` (the graduator
   whose `graduate`/`harvest` the launchpad is calling right now; zero, i.e. nobody, at any other
   time — including current and former graduators); then `_returned += msg.value`. Not
   `nonReentrant`. It writes storage, so graduators MUST return ETH with full-gas calls (a 2300-gas
   `transfer`/`send` fails, §2.2).
7. `fundMind(token)` — anyone, any phase/status, not pausable, `nonReentrant` (so a graduator cannot
   route its return through it during `graduate`/`harvest` and have it credited twice), `onlyMind`; `msg.value == 0` →
   `ZeroAmount()`; `mindBalance[token] += msg.value`; emit `MindFunded(token, msg.sender, msg.value)`.
   `MindFunded` is emitted only by `fundMind` (from = sender) and by `graduate`/`harvest`
   (from = graduator); fee shares emit `FeeAccrued` only.
8. `setMindConfig` — creator only (`NotCreator()`), `onlyMind`, any phase/status. `modelId != 0`
   else `InvalidModel()`; `bytes(metadataURI).length <= 2048` else `MetadataTooLong()`; stores the
   three fields; emits `MindConfigUpdated`.
9. Status. `MindStatus` is informational for the runner and gates nothing on-chain (trading,
   funding and draws work in every status).
   - `setCreatorPaused(token, paused)` — creator only (`NotCreator()`), `onlyMind`. `paused == true`: if status !=
     `Paused` set `Paused`. `paused == false`: if status == `Paused` set `Alive`. Emits
     `MindStatusChanged(token, newStatus)` only when the status changes; otherwise a no-op.
   - `setMindStatus(token, status)` — operator only (`NotOperator()`), `onlyMind`. Reverts
     `InvalidStatus()` if `status == Paused` or the current status is `Paused`. Toggles
     `Alive`/`Dormant`; emits `MindStatusChanged` only when the status changes.
10. `drawCompute(token, amount, receiptHash)` — operator only, `nonReentrant`, `onlyMind`, any
    status/phase (settles compute already incurred). `amount == 0` → `ZeroAmount()`;
    `amount > mindBalance[token]` → `InsufficientMindBalance()`. Epoch: if
    `block.timestamp >= epochStart + epochSeconds` then `epochStart = block.timestamp`, `drawn = 0`;
    then `drawn + amount > maxPerEpoch` → `DrawLimitExceeded()`. Epochs are fixed windows, so draws at
    the end of one epoch and the start of the next can take up to `2 · maxPerEpoch` within one
    `epochSeconds` interval (at most `2 · MAX_DRAW_PER_EPOCH` = 4 ether); this bound is accepted and
    documented in the NatSpec. Effects: `drawn += amount`,
    `mindBalance[token] -= amount`, emit `ComputeDrawn(token, amount, receiptHash)`; send `amount`
    to `computeTreasury`. `drawnInEpoch` returns the stored `(drawn, epochStart)` without applying
    an elapsed-epoch reset (callers compute the remaining allowance, §4.1 economics). Vault ETH
    leaves the contract only through `drawCompute`; nobody (creator, owner, operator) can withdraw
    it otherwise.
11. `anchorMemory` — operator only, `onlyMind`; emits `MemoryAnchored` only (no storage).
12. Owner setters (all `onlyOwner` → `OwnableUnauthorizedAccount(msg.sender)`): `setOperator`,
    `setTreasury`, `setComputeTreasury` revert `ZeroAddress()` on zero
    and emit their `…Updated` event. `setGraduator(newGraduator)` accepts zero (zero disables
    graduation; `graduate` then reverts `GraduatorNotSet()`) or a contract whose
    `IGraduator(newGraduator).launchpad() == address(this)` (checked with a `staticcall`: no code, a
    failing call, short return data or another launchpad → `InvalidGraduator()`), affects future
    graduations only and emits `GraduatorUpdated`. `setFeeParams` bounds: `tradeFeeBps <= 500`, `mindShareBps <= 10000`,
    `graduationFeeBps <= 1000` else `FeeTooHigh()`. `setDrawLimit` requires
    `epochSeconds >= 3600` and `maxPerEpoch <= MAX_DRAW_PER_EPOCH` (internal constant `2 ether`) else
    `InvalidDrawLimit()` (`maxPerEpoch` may be 0, which blocks draws). `setGraduationGrace(graceSeconds)`
    requires `3600 <= graceSeconds <= 30 days` else `InvalidGraduationGrace()` and emits
    `GraduationGraceUpdated(graceSeconds)`. `renounceOwnership()` always reverts `RenounceDisabled()`.
13. `pause()`/`unpause()` (owner) pause `createMind` and `buy` only; `sell`, `graduate`, `harvest`,
    `fundMind`, `drawCompute`, `anchorMemory`, status and config functions stay enabled.
14. `withdrawProtocolFees(to)` — `nonReentrant`; caller must be `owner()` or `treasury`, else
    `OwnableUnauthorizedAccount(msg.sender)`; `to == 0` → `ZeroAddress()`; `protocolBalance == 0` →
    `ZeroAmount()`; sets `protocolBalance = 0`, emits `ProtocolFeesWithdrawn(to, amount)`, sends.
15. Views: `quoteBuy`/`quoteSell` revert `NotAMind()`, `WrongPhase()` (`quoteBuy`: not `Bonding`;
    `quoteSell`: the rule-3 sell rule, i.e. not `Bonding` and not `Complete` past the grace),
    `ZeroAmount()` (zero input), `ExceedsTokensSold()` (sell) and otherwise return the §1 quote.
    `completedAt(token)` is the `block.timestamp` of the curve's last completion (0 before it and after
    a reopening sell; kept after graduation); `graduationGrace()` the current grace in seconds.
    `currentPrice` reverts `NotAMind()`, and `WrongPhase()` once `Graduated`; in `Bonding`/`Complete`
    it returns `CurveMath.price(realEthReserve, tokensSold)`. `getMind`/`getCurve` return zeroed
    structs for unknown tokens.

Invariants: `address(this).balance >= Σ realEthReserve + Σ mindBalance + protocolBalance`;
`token.balanceOf(launchpad) >= TOTAL_SUPPLY - tokensSold` while `Bonding`/`Complete`;
`completedAt[token] == 0` exactly while `Bonding`.

### 2.4 `UniswapV3Graduator` — `src/UniswapV3Graduator.sol`

`contract UniswapV3Graduator is IGraduator, IUniswapV3SwapCallback, Ownable2Step, ReentrancyGuard`.
`constructor(address initialOwner, address launchpad, address positionManager, address factory,
address weth9, uint24 feeTier)` — all addresses non-zero (`ZeroAddress()`); reads
`tickSpacing = factory.feeAmountTickSpacing(feeTier)` (zero → `UnsupportedFeeTier()`) and fixes
`tickLower = (-887272 / tickSpacing) * tickSpacing`, `tickUpper = -tickLower` (±887200 for the 1 %
tier); sets `priceToleranceBps = 100` and emits `PriceToleranceUpdated(100)`. The owner's only
privileged function is `setPriceToleranceBps(uint16)` (`onlyOwner`, at most 1000 else
`InvalidPriceTolerance()`, 0 allowed = exact price required; emits `PriceToleranceUpdated`); there is
no rescue path and the LP NFT can never leave the contract.

Public views: `launchpad()`, `positionManager()`, `factory()`, `weth9()`, `feeTier()` (`uint24`),
`tickLower()`/`tickUpper()` (`int24`), `priceToleranceBps()` (`uint16`),
`positionOf(address token) returns (uint256)`, `poolOf(address token) returns (address)`.
Events: `event GraduatedAtSkewedPrice(address indexed token, uint160 expectedSqrtPriceX96, uint160 actualSqrtPriceX96);`
(a correction swap was made; `actual` = pool price before it), `event PriceToleranceUpdated(uint16 toleranceBps);`.
Errors: `NotLaunchpad()`, `AlreadyGraduated()`, `NoPosition()`, `UnexpectedEthSender()`,
`UnsupportedFeeTier()`, `ZeroAddress()`, `EthTransferFailed()`,
`PoolPriceSkewed(uint160 expectedSqrtPriceX96, uint160 actualSqrtPriceX96)` (`actual` = price after the
correction; same selector as the `IMindLaunchpad` declaration), `UnauthorizedCallback()`,
`InvalidPriceTolerance()`.
`receive() external payable` accepts ETH only from `weth9` (unwraps), else `UnexpectedEthSender()`.
Local minimal interfaces in `src/interfaces/uniswap/` (do not import Uniswap packages):
`IWETH9` (`deposit() payable`, `withdraw(uint256)`, ERC20), `IUniswapV3Factory`
(`getPool`, `feeAmountTickSpacing`), `IUniswapV3Pool` (`slot0()`, `swap(address recipient, bool
zeroForOne, int256 amountSpecified, uint160 sqrtPriceLimitX96, bytes data) returns (int256 amount0,
int256 amount1)`) and, in the same file, `IUniswapV3SwapCallback`
(`uniswapV3SwapCallback(int256 amount0Delta, int256 amount1Delta, bytes data)`),
`INonfungiblePositionManager` (`createAndInitializePoolIfNecessary`, `mint(MintParams)`,
`collect(CollectParams)` with the canonical v3-periphery structs).

`graduate(token, tokenAmount)` — only launchpad, `nonReentrant`; `positionOf[token] != 0` →
`AlreadyGraduated()`:
1. `IWETH9(weth9).deposit{value: msg.value}()`. Order the pair: `token0 < token1`; `amount0`/`amount1`
   are the WETH (`msg.value`) and token (`tokenAmount`) amounts in that order.
2. `expected = SafeCast.toUint160(Math.sqrt(Math.mulDiv(amount1, 1 << 192, amount0)))` — derived
   solely from the received amounts.
3. `pool = positionManager.createAndInitializePoolIfNecessary(token0, token1, feeTier, expected)`
   (creates and/or initializes the pool if needed; leaves an already-initialized pool untouched).
   Read `actual = IUniswapV3Pool(pool).slot0().sqrtPriceX96`.
4. Price correction, only if `actual != expected` (anyone can create and initialize the pool at any
   price beforehand): `zeroForOne = actual > expected` (the price must fall: sell token0; otherwise
   sell token1 — i.e. WETH when the coin is too cheap, coins when it is too expensive);
   `cap = amountIn-side * 5000 / 10000` (at most 50 % of the side being sold); record the pool for the
   callback (`_swapPool = pool`), then `pool.swap(address(this), zeroForOne, int256(cap), expected,
   abi.encode(token0, token1))` (exact input, price limit = `expected`), clear `_swapPool`, and apply
   the returned deltas to `amount0`/`amount1` (positive = paid, negative = received). Where no
   liquidity lies between `actual` and `expected` the price moves there for free (zero deltas).
   Emit `GraduatedAtSkewedPrice(token, expected, actual)`. Liquidity the correction trades against is
   mispriced relative to `expected`: its owner sells to the graduator below, or buys from it above,
   the price implied by the amounts.
5. Re-read `price = slot0().sqrtPriceX96`; require `|price - expected| * 10000 <= expected *
   priceToleranceBps` (sqrt-price terms) else revert `PoolPriceSkewed(expected, price)` — nothing
   changes (the launchpad call reverts, the coin stays `Complete`) and anyone may retry once the pool
   has been arbitraged.
6. Desired amounts: the largest `(desired0, desired1) <= (amount0, amount1)` in the proportion
   `desired1 / desired0 = price² / 2^192` (the full range makes the exact proportion differ by
   < 1e-12); `forceApprove` them to the position manager; `mint` full range (`tickLower`, `tickUpper`,
   `amount{0,1}Desired = desired{0,1}`, `amount{0,1}Min = max(1, desired{0,1} * (10000 - 2 *
   priceToleranceBps - 100) / 10000)`, `recipient = address(this)`, `deadline = block.timestamp`);
   reset approvals to 0; store `positionOf[token] = tokenId`, `poolOf[token] = pool`.
7. Leftovers (`amount{0,1} - used{0,1}`): unused WETH → `withdraw` → send to the launchpad with a
   full-gas call (`ethReturned`, counted by its `receive()`); unused tokens → `safeTransfer` to
   0x…dEaD. Return `(pool, tokenId, ethReturned)`.

`uniswapV3SwapCallback(amount0Delta, amount1Delta, data)` — `msg.sender != _swapPool` →
`UnauthorizedCallback()` (so only the pool of the correction swap in progress can call it, and nobody
outside `graduate`); decodes `(token0, token1)` from `data` and `safeTransfer`s each positive delta of
that token to the pool. Zero deltas (a price move through a range without liquidity) owe nothing and
MUST NOT revert.

`harvest(token)` — only launchpad, `nonReentrant`; `positionOf[token] == 0` → `NoPosition()`.
`collect(tokenId, address(this), type(uint128).max, type(uint128).max)`; the WETH side is unwrapped
and sent to the launchpad (`ethOut`), the token side is transferred to 0x…dEaD (`tokensBurned`);
returns `(ethOut, tokensBurned)`.

### 3.2 Canonical JSON and hashes (normative)

`canonicalJson(value)` — the only serialization used under a hash:
- objects: keys sorted by Unicode code point (all keys in this spec are ASCII, so the default
  `Array.prototype.sort()` order applies), no whitespace, keys whose value is `undefined` omitted;
- arrays in order; strings escaped exactly as `JSON.stringify` does; `null`/`true`/`false` literal;
- numbers MUST be safe integers (anything else throws); `bigint` → decimal string (a JSON string);
- the resulting string is hashed as its UTF-8 bytes.

Hashes and URIs:
- **Metadata**: `metadataHash(meta) = sha256(utf8(canonicalJson(meta)))` as 64 lowercase hex chars
  **without** `0x` (viem `sha256`), where `meta` is the zod-validated `MindMetadata` object.
  `metadataUri(hash) = 'runner://metadata/' + hash`.
  `metadataDataUri(meta) = 'data:application/json;base64,' + base64(utf8(canonicalJson(meta)))`
  (standard base64 with padding).
- **Persona**: `personaHash(persona) = keccak256(toBytes(persona))` — UTF-8 bytes of the exact string,
  no trimming or newline normalization by anyone.
- **Model id**: `modelIdToHash(id) = keccak256(toBytes(id))`.
- **Memory item** `AnchorMemoryItem = { seq: number, kind: 'note'|'finding', content: string,
  url: string | null, createdAt: string /* ISO, §0.1 */ }`;
  `memoryContentHash(item) = keccak256(utf8(canonicalJson(item)))` (this is `Memory.contentHash`).
- **Anchor batch** `AnchorBatch = { token: string /* lowercase */, fromSeq: number, toSeq: number,
  memories: AnchorMemoryItem[] /* seq ascending, contiguous fromSeq..toSeq */ }`;
  `anchorBatchHash(batch) = keccak256(utf8(canonicalJson(batch)))` is the `contentHash` passed to
  `anchorMemory(token, toSeq, contentHash, uri)` with
  `uri = anchorBatchUri(token, fromSeq, toSeq) = 'runner://memories/' + token + '/' + fromSeq + '-' + toSeq`.
  `GET /api/minds/:token/memories/batch/:fromSeq-:toSeq` returns exactly this object.
- **Draw receipt** `DrawReceiptObject = { token: string /* lowercase */, fromTickId: number,
  toTickId: number, ticks: Array<{ tickId: number, model: string, inputTokens: number,
  outputTokens: number, cacheReadTokens: number, cacheWriteTokens: number, costUsdMicro: number }>
  /* tickId ascending */, ethUsdPriceMicro: number, amountWei: string /* decimal */ }`;
  `drawReceiptHash(receipt) = keccak256(utf8(canonicalJson(receipt)))` is the `receiptHash` passed to
  `drawCompute`. `fromTickId`/`toTickId` are the min/max `tickId` in `ticks`. Served in
  `GET /api/minds/:token/compute` (`receipts[].receipt`).

### 4.1 Modules

- **`db/`** — `node:sqlite` `DatabaseSync(DB_PATH)`; on open: `PRAGMA journal_mode=WAL;
  synchronous=NORMAL; foreign_keys=ON; busy_timeout=5000`. One schema module applied idempotently
  (tracked with `PRAGMA user_version`). uint256/wei/token values are stored as `TEXT` decimal
  strings; where a list is sorted by such a value (market cap) an auxiliary `REAL` column holds an
  approximate copy used only for `ORDER BY`. Timestamps are stored as INTEGER unix ms, hashes and
  addresses as lowercase hex TEXT. FTS5 detection: create `memories_fts` (`fts5`, external content)
  inside try/catch; on failure `recall` falls back to `LIKE`. Exactly one runner process owns the
  DB; the web never opens it. Suggested tables: `minds`, `trades`, `fee_accruals`, `fundings`,
  `draws`, `harvests`, `anchors`, `memories`, `thoughts`, `ticks`, `receipts`, `metadata`,
  `indexer_state`, `blocks`.
- **`chain/`** — `clients.ts`: viem `publicClient` (http transport on `RPC_URL`, chain from
  `chainById(CHAIN_ID)`) and `walletClient` (operator account) when not dry-run.
  `launchpad.ts`: typed reads (`getMind`, `getCurve`, `mindBalance`, `drawLimit`, `drawnInEpoch`,
  `feeParams`, `operator`) and writes (`drawCompute`, `anchorMemory`, `setMindStatus`, `graduate`,
  `harvest`) using `mindLaunchpadAbi`. `txQueue.ts`: every operator transaction goes through one
  FIFO queue — simulate (`simulateContract`), send, wait for the receipt (60 s timeout) before the
  next. In dry run the queue records the intent (log + `dry_run` status rows) and sends nothing.
  At startup the runner checks `operator()` equals the operator account and forces dry run (with an
  error log) if not.
- **`indexer/`** — polls `eth_getLogs` for the launchpad address (all §2.3 events, decoded with
  viem `parseEventLogs`) every 1000 ms over ranges of ≤ 2000 blocks from `last_processed_block + 1`
  up to `head - CONFIRMATIONS`. Logs are applied in `(blockNumber, logIndex)` order; each range is
  persisted in ONE transaction together with `indexer_state.last_processed_block`; inserts are
  idempotent on `(tx_hash, log_index)`; restart resumes from `indexer_state`. Block timestamps come
  from `getBlock` (cached per block number). Derived state: minds (info, status, metadata fields),
  curves (reserves, phase, pool, positionId, final price), `mindBalanceWei` (Σ `FeeAccrued.mindAmount`
  + Σ `MindFunded.amount` − Σ `ComputeDrawn.amount`, exact because every vault change is evented),
  trades, fundings, draws, anchors, harvests. After a range commits, the indexer emits in-process
  events: `mind:created`, `mind:config`, `mind:status`, `trade`, `fee:accrued`, `mind:funded`,
  `curve:complete`, `graduated`, `compute:drawn`, `memory:anchored`, `harvested` — **only for logs
  in blocks ≥ the head observed at startup** ("live"). Replayed history never triggers side effects
  (graduate, harvest, status or settlement txs). The indexer reports `live = true` once it has
  processed up to the startup head.
- **`metadata/`** — `POST /api/metadata` storage and resolution of `metadataURI` (on `mind:created`,
  `mind:config`, and at startup for minds whose metadata is unresolved). Supported schemes:
  `runner://metadata/<hash>` (local table), `data:application/json;base64,…`, `ipfs://<cid>[/path]`
  (fetched from `IPFS_GATEWAY + <cid>[/path]`) and `http(s)://` (best effort: 5 s timeout, 64 KB cap,
  same address checks as the browser filter). The document is parsed with the `mindMetadataSchema`
  shape in strip mode (unknown keys ignored). Any failure → every metadata-derived field is `null`.
  `personaVerified = personaHash(meta.persona) === onchain personaHash`; an unverified persona is neither served nor
  used by the mind. `image` is normalized: `http(s)://` kept, `ipfs://x` → `IPFS_GATEWAY + x`,
  anything else → `null`. The on-chain `name`, `symbol` and `modelId` are authoritative; the
  metadata copies are informational.
- **`economics/`** — all USD math in integer micro-USD.
  - `ethUsdMicro()`: from `ETH_USD_FEED` (`latestRoundData()` + `decimals()`; rejected if
    `answer <= 0` or `updatedAt` older than 3600 s → fall back to `ETH_USD_PRICE` and log), cached
    60 s; `ETH_USD_PRICE` converts as `Math.round(price·1e6)`; `usdMicroOfWei(wei) = wei·ethUsdMicro / 1e18` (floor);
    `weiOfUsdMicro(usd) = ceilDiv(usd·1e18, ethUsdMicro)`.
  - Cost: each iteration's final message is charged `costOfUsageMicroUsd(message.model,
    message.usage)` — the **served** model (`message.model`), never the requested one; unknown
    served models are charged at `claude-fable-5-1` prices and logged. A tick's cost is the sum
    over its iterations, including aborted and failed ticks (usage of an iteration whose stream
    broke is taken from the last `message_start`/`message_delta` usage seen, if any).
  - Per mind: `balanceUsdMicro = usdMicroOfWei(mindBalanceWei)`;
    `unsettledUsdMicro` = Σ cost of the mind's ticks not covered by a `confirmed` receipt;
    `epochRemainingWei = maxPerEpoch` if `now >= epochStart + epochSeconds` (`now` = latest block
    timestamp), else `max(0, maxPerEpoch - drawn)` (from `drawLimit()`/`drawnInEpoch()`, cached 60 s
    and invalidated after every draw);
    `availableUsdMicro = usdMicroOfWei(min(mindBalanceWei, epochRemainingWei)) - unsettledUsdMicro`;
    `vaultUsdMicro = max(0, balanceUsdMicro - unsettledUsdMicro)`.
    `runnableThresholdUsd = max(MIN_TICK_BUDGET_USD, MAX_TICK_COST_USD)`.
  - Burn governor: `dailyBudgetUsd = max(vaultUsd / TARGET_RUNWAY_DAYS, MIN_DAILY_SPEND_USD)`;
    `avgTickCostUsd` = mean cost of the mind's last 20 ticks (`MAX_TICK_COST_USD` when it has none);
    `tickIntervalMs = max(TICK_INTERVAL_MS, 86400000·avgTickCostUsd / dailyBudgetUsd)`;
    `nextTickAt = lastTickEndedAt + tickIntervalMs`.
  - Reporting: `burnUsdPerHour` = Σ cost of ticks started in the last 6 h ÷ 6;
    `runwayHours = burnUsdPerHour > 0 ? vaultUsd / burnUsdPerHour : null`.
  - Settlement (`settle(mind)`): runs after a tick when `unsettledUsd >= DRAW_THRESHOLD_USD`, and
    unconditionally (any amount > 0) before the runner sets a mind `Dormant` and after it observes
    `Paused`; it does nothing when no tick is eligible. Eligible ticks: the mind's ticks with no
    receipt or a `failed` one, in `tickId` order.
    `cap = min(mindBalanceWei, epochRemainingWei)`; include ticks greedily while
    `weiOfUsdMicro(Σ costUsdMicro) <= cap`; if not even the first tick fits and the cap is limited
    by the balance (not the epoch), include that tick alone with `amountWei = mindBalanceWei` (the
    shortfall is absorbed by the operator); if the epoch limits, wait for the next epoch; if
    `cap == 0` nothing is drawn (the ticks stay unsettled and the mind is not runnable). Build the
    `DrawReceiptObject` (§3.2) with `ethUsdPriceMicro` at settlement time and
    `amountWei = min(weiOfUsdMicro(Σ cost), cap)`, insert the receipt row (`pending`, or `dry_run`
    in dry run) **before** sending `drawCompute(token, amountWei, receiptHash)`; a successful tx
    stores `txHash`, and the receipt becomes `confirmed` when the indexer commits the matching
    `ComputeDrawn` log (so the vault balance and the unsettled sum change together); a reverted or
    unsent tx → `failed` (ticks become eligible again). At startup, `pending` receipts are
    reconciled against indexed `ComputeDrawn` logs by `receiptHash` (match → `confirmed`; no match
    after 10 min → `failed`). `dry_run` receipts never count as
    settled, so a dry-run mind still runs out of budget.
- **`browser/`** — one Chromium (`chromium.launch({ headless: BROWSER_HEADLESS })`), relaunched
  on `browser.on('disconnected')`. One `BrowserContext` per mind, created lazily at tick start and
  kept in an LRU of `2 × MAX_CONCURRENT_MINDS` contexts (evicted contexts are closed; the next tick
  starts on `about:blank`). Context options: viewport 1280×800, default UA, JS on,
  `acceptDownloads: false`, `serviceWorkers: 'block'`, no permissions. Egress filter (also used by
  the metadata fetcher and inside tool `run` before navigating):
  - only `http:`/`https:` URLs without credentials; raw IP literals (any notation, including
    IPv4-mapped IPv6) are checked directly; hostnames are resolved with
    `dns.lookup(host, { all: true })` and blocked if ANY address is loopback, private
    (10/8, 172.16/12, 192.168/16, fc00::/7), link-local (169.254/16, fe80::/10), CGNAT (100.64/10),
    multicast, unspecified, broadcast, or an IPv4-mapped IPv6 form of these;
  - `context.route('**/*', handler)` (async) applies the filter to every request (navigations,
    subresources, XHR/fetch). Because Playwright does not re-invoke route handlers for redirect
    hops, the handler fetches allowed requests itself with `route.fetch({ maxRedirects: 0 })`,
    validates any `Location` target of a 3xx before `route.fulfill({ response })`, and aborts
    blocked requests with `route.abort('blockedbyclient')`;
  - `context.routeWebSocket(/.*/, ws => …)` applies the same filter to WebSockets (blocked → close,
    allowed → `connectToServer()`);
  - pop-ups are closed (`context.on('page')` for any page other than the mind's), dialogs dismissed
    (`page.on('dialog', d => d.dismiss())`), `page.setDefaultNavigationTimeout(20000)`,
    `page.setDefaultTimeout(15000)`, `page.on('crash')` recreates the page.
  The filter takes an injectable resolver so unit tests can cover it without network.
  `MindBrowser` actions: `navigate(url)` (`waitUntil: 'domcontentloaded'`), `read()` →
  `{ url, title, text, links }` (`text` ≤ 6000 chars from `main`/`article`/`body` innerText with
  collapsed whitespace, computed in `page.evaluate` over at most 2 MB of DOM text; `links` ≤ 60
  `{ i, text, href }` with absolute http(s) hrefs), `click({ link } | { selector })`,
  `type(selector, text, submit)`, `scroll('up' | 'down')`, `back()`, `screenshot()` → JPEG captured
  with CDP `Page.captureScreenshot({ format: 'jpeg', quality: 55, clip: { x: 0, y: 0, width: 1280,
  height: 800, scale: 0.7 } })` (896×560) as base64. While a tick runs, frames are captured at
  `FRAME_FPS` and once after each action, stored as the mind's last frame and broadcast (§6).
- **`memory/`** — table `memories(mind, seq, kind 'note'|'finding', content, url, created_at,
  content_hash)`; `seq` starts at 1 per mind and is contiguous; `content_hash =
  memoryContentHash(item)`. `remember(mind, kind, content, url)`, `recall(mind, query, limit)`
  (FTS5 bm25 order, else `LIKE` newest first), `recent(mind, n)`. Each new memory is broadcast
  (§6). Anchoring: whenever a mind has `ANCHOR_EVERY_N_MEMORIES` unanchored memories, the next
  contiguous batch `[fromSeq, toSeq]` is hashed (`anchorBatchHash`), an `anchors` row is inserted
  (`pending`, or `dry_run`) before `anchorMemory(token, toSeq, contentHash, uri)` is queued; on
  receipt → `confirmed` with `txHash`. At startup, `pending` anchors are reconciled against indexed
  `MemoryAnchored(token, seq)` logs before any new anchor is sent.
- **`mind/persona.ts`** — returns
  `system: [{ type: 'text', text: STABLE_PREFIX, cache_control: { type: 'ephemeral' } }, { type: 'text', text: dynamicTrailer }]`.
  `STABLE_PREFIX` is deterministic for `(token, name, symbol, modelId, personaHash)` and contains no
  timestamps, balances or URLs: identity ("You are the mind of $SYMBOL (name), a coin living on
  Robinhood Chain…"), the creator's persona (only if `personaVerified`, otherwise
  "No persona was provided."), and the rules (explore the open web, be curious and honest, record
  findings with `remember`, share short public thoughts with `think_aloud`; never log in, never
  enter personal data, never buy anything, never try to bypass blocks or paywalls; your compute is
  paid by the coin's trading fees — you exist while the vault lasts). `dynamicTrailer`: current
  date-time (minute precision, UTC), vault USD and runway, this tick's spend cap
  (`MAX_TICK_COST_USD`), the last 10 memories (seq, kind, content ≤ 200 chars) and the current URL.
- **`mind/tools.ts`** — `betaZodTool` definitions (from `@anthropic-ai/sdk/helpers/beta/zod`), each
  spread as `{ ...tool, eager_input_streaming: true }`. The tools array is built once per process
  in this fixed order with fixed descriptions (no per-mind text), so it is byte-stable:

  | name | input (zod) | result |
  |---|---|---|
  | `browse_navigate` | `{ url: string(http/https, ≤ 2048) }` | `read()` result as JSON text |
  | `browse_read` | `{}` | `read()` result as JSON text |
  | `browse_click` | `{ link?: int ≥ 0, selector?: string ≤ 300 }` (exactly one) | `read()` result |
  | `browse_type` | `{ selector: string ≤ 300, text: string ≤ 500, submit?: boolean }` | `read()` result |
  | `browse_scroll` | `{ direction: 'up' \| 'down' }` | `read()` result |
  | `browse_back` | `{}` | `read()` result |
  | `browse_screenshot` | `{}` | one image block (`image/jpeg`, base64) |
  | `remember` | `{ kind: 'note' \| 'finding', content: string 1..2000, url?: string ≤ 2048 }` | `{ seq }` |
  | `recall` | `{ query: string 1..200, limit?: int 1..20 (default 8) }` | memories as JSON text |
  | `think_aloud` | `{ text: string 1..280 }` | `"ok"` |

  Tool failures (blocked URL, timeout, missing element) are returned as text results starting with
  `error:`; `run` never throws for expected failures. `browse_navigate` re-validates the URL with
  the egress filter before navigating.
- **`mind/tick.ts`** — one tick of one mind:

  ```ts
  const runner = client.beta.messages.toolRunner({
    model: spec.id,
    max_tokens: spec.maxTokens,               // 16000 (5.x) | 8192 (haiku-4-5)
    tools,                                    // byte-stable array from tools.ts
    system,                                   // persona.ts (cached prefix + trailer)
    cache_control: { type: 'ephemeral' },     // SHOULD: automatic caching of the growing tool-result tail
    messages: [{ role: 'user', content: TICK_PROMPT }],
    stream: true,
    max_iterations: TICK_MAX_ITERATIONS,
    // opus-5-5, sonnet-5-5, fable-5-1:
    thinking: { type: 'adaptive', display: 'summarized' },
    output_config: { effort: 'medium' },
    betas: ['server-side-fallback-2026-07-01'],
    fallbacks: 'default',
    // haiku-4-5 instead: thinking: { type: 'enabled', budget_tokens: 2048 }, and NO output_config,
    // NO betas, NO fallbacks.
  });
  ```

  Never set `tool_choice` to `any`/`tool`, never send `budget_tokens` or `thinking.type: 'disabled'`
  to a 5.x model. Use SDK types (`Anthropic.Beta.BetaMessageParam`, `Anthropic.Beta.BetaUsage`, …),
  never redefinitions. `TICK_PROMPT` is a constant ("Continue living. …: look at your recent
  memories, decide what to explore next, use your tools, record what you learn, think aloud
  briefly, and end with a one-paragraph summary of what you did."). For each iteration
  (`for await (const stream of runner)`): forward text and thinking deltas to the bus as WS
  `thought` messages (§6); then `const message = await stream.finalMessage()`; charge it (economics);
  emit an `action` message for each `tool_use`; then check `message.stop_reason`: `refusal` → end the
  tick (not a failure); `max_tokens` while the message contains a `tool_use` → abort the tick (a
  failure, `error: 'max_tokens_with_tool_use'`);
  if the tick's running cost ≥ `MAX_TICK_COST_USD` → stop iterating (overshoot of at most one
  iteration is accepted). On a tool-input JSON parse error, rebuild the runner once from
  `runner.params` and continue; a second one fails the tick. `Anthropic.RateLimitError` and
  `Anthropic.APIError` with `status >= 500` (and connection errors) are retried up to 3 times per
  tick with exponential backoff (1 s, 2 s, 4 s, or `retry-after` when present) by rebuilding the
  runner from `runner.params`; the SDK client is created with `maxRetries: 0`. Every tick gets an
  `AbortController`; at `TICK_TIMEOUT_MS` the in-flight request is aborted, iteration stops, and the
  mind's browser context is closed and recreated. Persistence: a `ticks` row (id, mind, started_at,
  ended_at, requested model, served model of the last iteration, iterations, token counts,
  cost_usd_micro, stop_reason, error); `think_aloud` inputs → `Thought { kind: 'aloud' }`; the
  tick's final assistant text (if non-empty) → `Thought { kind: 'summary' }`; each saved thought is
  broadcast as `thoughtSaved`.
- **`mind/scheduler.ts`** — starts only when the indexer is live and `ANTHROPIC_API_KEY` is set.
  Every 1000 ms it fills free slots (`MAX_CONCURRENT_MINDS − inFlight`) with eligible minds ordered
  by `nextTickAt` ascending. Eligible = on-chain status `Alive`, model known (`modelById(modelId)`),
  not in flight (single-flight per mind via an in-memory lock), not cooling, `now >= nextTickAt`,
  `availableUsd >= runnableThresholdUsd`. After a tick: if it failed (exception after retries,
  timeout, JSON failure), increment the mind's consecutive-failure counter; at 3 the mind is marked
  locally **cooling** for 1 h (no on-chain tx); a successful tick resets the counter.
  Status management (txs via the queue; at most one status tx per mind per 60 s; never for
  `Paused` minds): after each tick and on live `fee:accrued`/`mind:funded`/`compute:drawn`/
  `mind:status`/`mind:config` events, re-evaluate: `Alive` and (`availableUsd < runnableThresholdUsd`
  or model unknown) → `settle()` then `setMindStatus(Dormant)`; `Dormant` and model known and
  `availableUsd >= 2 × runnableThresholdUsd` → `setMindStatus(Alive)`. A creator pause observed
  mid-tick lets the tick finish, then settles. Graduation: on a live `curve:complete` event, and
  once when the indexer becomes live for every mind in phase `Complete`, re-read `getCurve`; if still
  `Complete` queue `graduate(token)`. Harvest: every `HARVEST_INTERVAL_MS`, for every graduated mind
  with `positionId != 0`, re-read the phase and queue `harvest(token)`. Graduate/harvest are best
  effort (failures logged), guarded by dry run, and skipped when the on-chain phase changed.
- **`stream/`** — in-process bus keyed by mind for frames, thoughts, actions, memories, status,
  budget and trades; the WS server (§6) subscribes per connection.
- **`api/`** — Hono app on `@hono/node-server` serving §5 under `/api`, CORS for the
  `PUBLIC_WEB_ORIGIN` list; a `ws` `WebSocketServer({ noServer: true })` handles upgrades on `/ws`
  of the same HTTP server (§6).
- **`main.ts`** — open DB → start indexer → API/WS → scheduler once live. Graceful shutdown
  (SIGINT/SIGTERM): stop picking ticks, abort in-flight ticks, wait for the tx queue (≤ 30 s), close
  browser, close DB.

### 4.2 Tests (vitest)

No test may call the Anthropic API or a real RPC. Required: cost charging with the served model
(served ≠ requested model, unknown model) and the budget/governor/settlement policy (table-driven, fake clock); egress filter (IP
classes, IPv4-mapped IPv6, hostnames resolving to private addresses through a stub resolver,
redirect to a blocked target, websocket); page text extraction on a static HTML page (Playwright,
headless; skipped when Chromium is missing); indexer idempotency, ordering and live/replay
separation against a fake log source; scheduler with a fake clock and fake tick (no concurrent ticks
per mind, slot refill, timeout abort, cooling after 3 failures); API handlers with an in-memory DB
(DTOs parse with the shared schemas); `POST /api/metadata` validation and hashing; tool input
validation (bad URL rejected); request-shape builder per model (5.x vs haiku).

## 5. HTTP API (runner, JSON)

All routes live under `/api` on `PORT`. Conventions of §0.1 apply (lowercase addresses, decimal
strings for wei/token amounts, ISO timestamps, `null` for unknown). Errors: status 400 (invalid
param/body), 404 (unknown mind/hash/range), 413 (body too large), 429 (rate limited), 500, with body
`ApiError = { error: string }`. Path parameter `:token` is a 0x address (any case; normalized).

| Route | Query / body | Response |
|---|---|---|
| `GET /api/health` | — | `HealthResponse` |
| `GET /api/minds` | `sort=created\|mcap\|activity` (default `created`), `limit` 1..200 (default 50), `cursor` | `MindsResponse` |
| `GET /api/minds/:token` | — | `MindDetail` |
| `GET /api/minds/:token/trades` | `limit` 1..500 (default 100) | `Trade[]`, newest first by `(blockNumber, logIndex)` |
| `GET /api/minds/:token/memories` | `limit` 1..200 (default 50), `before` (seq, exclusive) | `Memory[]`, `seq` descending |
| `GET /api/minds/:token/memories/batch/:fromSeq-:toSeq` | — | `AnchorBatch` (§3.2) — exactly the hashed object; 404 unless every seq of the range exists (max 1000 items) |
| `GET /api/minds/:token/thoughts` | `limit` 1..500 (default 100) | `Thought[]`, newest first |
| `GET /api/minds/:token/compute` | — | `ComputeResponse` |
| `GET /api/minds/:token/frame.jpg` | — | last frame, `image/jpeg`, `Cache-Control: no-store`; 404 when none |
| `GET /api/models` | — | `PublicModel[]` (catalog order) |
| `GET /api/stats` | — | `StatsResponse` |
| `POST /api/metadata` | `MindMetadata` JSON, ≤ 32768 bytes, `Content-Type: application/json` | `MetadataUploadResponse` (200, idempotent) |
| `GET /api/metadata/:hash` | `hash` = 64 lowercase hex | the stored `MindMetadata` JSON, `Cache-Control: public, max-age=31536000, immutable` |

`mindMetadataSchema` is a strict object (unknown keys rejected; empty strings are invalid, so
clients omit empty optional fields). The runner's resolver (§4.1) parses external documents with the
same shape in strip mode. `POST /api/metadata`: the body is validated with `mindMetadataSchema` (→ 400),
`hash = metadataHash(meta)`, stored (deduplicated by hash), response
`{ uri: metadataUri(hash), hash, personaHash: personaHash(meta.persona) }`. Global rate limit
60 requests/min (429).

Sorting of `GET /api/minds`: `created` = `createdAt` desc; `mcap` = `marketCapWei` desc; `activity` =
`lastTickAt` desc, nulls last; ties broken by `createdAt` desc then `token` asc. `cursor` is an opaque
base64url string from the previous `nextCursor` (`null` when exhausted).

Definitions: gross ETH of a trade = `ethAmountWei` for buys, `ethAmountWei + feeWei` for sells.
`trades24h`/`volume24hWei` = count / Σ gross ETH of trades whose block timestamp ≥ now − 24 h.
`priceWei` = spot price after the trade (`Trade`) or now (`MindSummary`) = `x·1e18/y`; once
graduated, `MindSummary.priceWei` is the frozen final curve price (computed from
`CurveCompleted.realEthReserve` and `tokensSold = CURVE_SUPPLY`; the DEX price is not tracked) and
`realEthReserveWei = "0"`. `HealthResponse.activeMinds` = ticks currently in flight.

## 6. WebSocket protocol (`/ws?token=0x…`)

- One subscription per connection, chosen by the `token` query parameter. Malformed or missing
  token → `{ type: 'error', message }` then close 1008. Token not (yet) indexed →
  `{ type: 'error', message: 'unknown token' }` then close 4404 (clients retry after 3 s, at most
  10 times — a freshly created mind may not be indexed yet). More than 100 connections for one mind →
  close 1013. No `Origin` check (the stream is public and read-only).
- On open the server sends `hello`. A client `subscribe` replaces the subscription and is answered
  with a new `hello` (unknown token → `error`, previous subscription kept).
- Each connection has an outbound queue. A `frame` is dropped when `ws.bufferedAmount > 1_000_000`;
  if `bufferedAmount > 4_000_000` the connection is closed with 1013. Other messages are sent in order.
- The server sends protocol-level pings every 25 s and terminates connections that did not answer
  the previous ping. A client `{ type: 'ping' }` is answered with `{ type: 'pong' }`. Unparsable
  client messages or messages > 1 KB are answered with `error` (the connection stays open).
- Frames are captured once per mind and shared by all its subscribers.

```ts
type WsFrameData = { jpegBase64: string; url: string; at: Iso };
type WsServerMessage =
  | { type: 'hello'; token: Hex; status: MindStatusName; phase: CurvePhaseName; frame: WsFrameData | null; at: Iso }
  | ({ type: 'frame' } & WsFrameData)                       // ≤ FRAME_FPS per second while ticking
  | { type: 'thought'; tickId: number; kind: 'text' | 'thinking'; text: string; delta: boolean; at: Iso }
  | { type: 'thoughtSaved'; thought: Thought }              // a persisted 'aloud' or 'summary' thought
  | { type: 'action'; tickId: number; tool: string; input: string /* redactActionInput, ≤ 300 chars */; at: Iso }
  | { type: 'memory'; memory: Memory }
  | { type: 'status'; status: MindStatusName; phase: CurvePhaseName; at: Iso }
  | { type: 'budget'; balanceWei: Wei; balanceUsd: number; burnUsdPerHour: number; runwayHours: number | null; at: Iso }
  | { type: 'trade'; trade: Trade }
  | { type: 'pong' }
  | { type: 'error'; message: string };
type WsClientMessage = { type: 'subscribe'; token: Hex } | { type: 'ping' };
```

`thought` semantics: for each assistant `text` block and each summarized `thinking` block the
runner sends `delta: true` messages whose `text` is the next fragment, then exactly one
`delta: false` message whose `text` is the full block text (clients replace their buffer with it).
Blocks of one tick stream sequentially, so a client keeps one buffer per `(tickId, kind)` and starts a
new one after a `delta: false`. `action` is sent for every tool call (including `think_aloud`);
`thoughtSaved` when an `aloud`/`summary` thought is stored; `status` on live `MindStatusChanged`
and phase changes (`CurveCompleted`, `Graduated`); `budget` after each tick and on vault changes; `trade` on each live
`Trade` event. Zod schemas: `wsServerMessageSchema`, `wsClientMessageSchema` (plus one schema per
message, e.g. `wsThoughtSchema`, `wsThoughtSavedSchema`, `wsPongSchema`, `wsErrorSchema`).

and mapped to copy for every §2.3 error. Explorer links only via `explorerTxUrl` /
`explorerAddressUrl` / `explorerTokenUrl` (no hard-coded URLs; plain text when undefined).
API responses and WS messages are parsed with the shared zod schemas. The model list falls back to
`MODELS` from `@www-rh/shared` when `/api/models` fails.

Routes:
- `/` — grid of `MindSummary` cards from `GET /api/minds`: image, name/$symbol, status dot

  (`model ?? 'unsupported model'`), price & mcap (ETH), progress bar to graduation, live thumbnail

  1. Build `MindMetadata` (empty optional fields omitted; validated client-side with `mindMetadataSchema`).
  2. `POST /api/metadata` → `metadataURI = uri`, `personaHash` from the response. If the runner is
     unreachable (network error or 5xx), fall back to `metadataURI = metadataDataUri(meta)` and
     `personaHash = personaHash(meta.persona)` computed locally; if that data URI exceeds
     `MAX_METADATA_URI_BYTES` (2048) the form refuses to submit and asks to shorten the
     persona/description or retry later.
  3. `modelId = modelIdToHash(model)`. Read `creationFee()` and `feeParams()` immediately before
     submitting. Quote the initial buy with shared `quoteBuy(INITIAL_RESERVES, initialBuyWei,
     tradeFeeBps)`; `minTokensOut = applySlippage(quote.tokensOut, slippageBps)` (default 100 bps;
     0 when the initial buy is 0).
  4. `createMind(name, symbol, metadataURI, modelId, personaHash, minTokensOut)` with
     `value = creationFee + initialBuyWei`.
  5. From the receipt, decode `MindCreated` with `parseEventLogs({ abi: mindLaunchpadAbi,
     eventName: 'MindCreated', logs })` to get `token`; if seed compute > 0, send
     `fundMind(token)` with that value as a second step (a 2-step stepper; skipping or failing it
     still navigates); navigate to `/mind/<token>`.
- `/mind/:token` — on-chain reads (`getMind`, `getCurve`) work immediately; while the API returns 404
  the page shows "indexing…" and polls every 2 s. Three columns:
  (1) **stream**: live frame (WS `hello.frame`/`frame`), current URL, thoughts ticker (WS `thought`
  buffers and `thoughtSaved`; `thinking` behind a toggle), action log (WS `action`);
  (2) **trade**: curve stats (price, mcap, progress, reserve), buy/sell panel with quotes from
  `quoteBuy`/`quoteSell` reads (debounced input, refetch every 2 s), slippage 10..2000 bps (default
  100), `deadline = now + 600 s`; sell checks `allowance` and approves exactly `tokensIn` before
  `sell` (2 steps). Phase `complete` → "Graduate" button (`graduate(token)`, anyone; a
  `WrongPhase()` revert means someone else graduated it — refetch, no error). Phase `graduated` →
  links to the explorer token page (`explorerTokenUrl(chain, token)`) and pool page
  (`explorerAddressUrl(chain, pool)`; labelled "MockGraduator (no DEX)" when `positionId == "0"`),
  plus a "Harvest fees" button (`harvest(token)`, anyone). No Uniswap app deep link.
  (3) **mind**: model, persona (or "persona not verified"), compute meter from
  `GET /api/minds/:token/compute` + WS `budget` (balance ETH/USD, burn/h, runway), "feed the mind"
  (`fundMind`), memories list with anchor tx links, compute draws (`receipts`: amount, tick range,

  model/persona (same metadata flow as `/create` → `setMindConfig(token, modelIdToHash(model),
